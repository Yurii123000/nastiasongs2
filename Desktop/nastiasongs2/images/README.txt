ИНСТРУКЦИЯ ПО ИЗОБРАЖЕНИЯМ:
============================
В эту папку вы можете поместить свои изображения:

1. background.jpg (или background.png)
   - Фоновая картинка для всего сайта.
   - Если картинка не добавлена, сайт будет использовать красивый сине-розовый фирменный градиент.
   - Когда вы положите сюда файл с именем "background.jpg" (или background.png), сайт автоматически покажет его как фон с красивым мягким затемнением.

2. qr-privatbank.png (или qr-privatbank.jpg)
   - Картинка с вашим QR-кодом ПриватБанка для пожертвований (доната).
   - Она будет отображаться в самом низу сайта в блоке "Поддержать творчество / Підтримати творчість".
   - Пока вы не добавили свой файл, сайт отображает стильную заготовку-плейсхолдер с логотипом ПриватБанка.
